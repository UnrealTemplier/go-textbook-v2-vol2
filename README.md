# Том 2. Базы данных: от SQL и моделирования до движков и HighLoad

> Фундаментальный учебник по базам данных для Go-разработчика: реляционная модель, SQL с нуля, индексы и `EXPLAIN`, транзакции, MVCC и WAL, движки PostgreSQL и MySQL/InnoDB, репликация и шардирование, NoSQL, ClickHouse, векторные индексы и промышленная практика в Go.

* **Серия:** `go-textbook-v2` (Том 2 из 7)
* **Версия тома:** `0.9.0` (контент, сквозной проект и иллюстрации собраны и проверены; впереди Фактчек v5 → `1.0.0`)
* **Входные требования:** Пройден Том 1 (базовый Go, `net/http`, вводные структуры данных и алгоритмы).
* **Целевая версия Go:** `Go 1.24` (`go 1.24` в `project/go.mod`)
* **Движок:** `html-textbook-engine` (100% Offline-First, сборка в `dist/` для `file:///` и GitHub Pages)

## Сквозной проект тома (`project/`)

`LedgerPulse` — подсистема финансового учёта с двойной записью и аналитическая витрина (`project/step01/`..`project/step07/`, `project/final/`, миграции `project/sql/migrations/001..003`, схема ClickHouse `project/sql/clickhouse/001_ledger_events.sql` и `docker-compose.yml`), включая чистый Go-драйвер `ledgerdriver` поверх `database/sql/driver` для воспроизводимого запуска тестов без внешнего инстанса БД.

Запуск тестов проекта с детектором гонок:
```bash
cd project && go vet ./... && go test -race -count=1 ./...
```

```bash
python3 -m engine.build --all --strict
python3 -m engine.audit --strict --no-mermaid-runtime
```
