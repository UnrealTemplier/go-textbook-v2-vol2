Добро пожаловать в **Том 2. Базы данных: от SQL и моделирования до движков и HighLoad**! Этот том задуман как строго линейный учебник: каждая глава опирается только на то, что вы уже прошли ранее.

## Как устроен каждый урок

1. Короткая мотивация и наглядная модель — прежде чем вводить сухие термины.
2. Осмысленные примеры кода под `Go 1.22–1.24`.
3. Разбор типичных ловушек и ошибок.
4. Небольшие практические упражнения прямо в конце урока со сворачиваемыми решениями.

## Пример упражнения и сворачиваемого решения

> [!practice] Пробное упражнение
> Напишите простую функцию `Greeting(name string) string`, которая возвращает приветствие вида `"Привет, Go!"`.

> [!solution] Показать решение
> ```go
> package step00
>
> import "fmt"
>
> func Greeting(name string) string {
>     return fmt.Sprintf("Привет, %s!", name)
> }
> ```
>
> Если блок выше аккуратно раскрывается по клику и код подсвечен, значит каркас тома и хук `book/hooks.py` работают корректно.
